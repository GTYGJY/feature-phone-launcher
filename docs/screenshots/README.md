# 截图目录

把应用截图放在本目录，并按下面的文件名命名，README 中的截图区块即可直接引用（取消注释即可显示）。

| 文件名 | 内容 | 建议 |
|--------|------|------|
| `01-idle.png` | 待机界面（大时钟 + 农历 + 运营商） | 竖屏 1080×2400 左右 |
| `02-menu.png` | 菜单界面（含选中反色项） | 同上 |
| `03-dialer.png` | 拨号界面（号码 + T9 匹配列表） | 最好有匹配结果 |
| `04-contacts.png` | 通讯录列表 | |
| `05-call-log.png` | 通话记录列表 | |
| `06-messages.png` | 信息列表 | |
| `07-color.png` | 颜色设置页 | |
| `08-display.png` | 显示设置页（字体大小 / 模块选择） | |
| `09-about.png` | 关于页（显示版本号） | |

建议：

- 统一使用同一台设备、同一套配色（默认米白 / 黑键）拍摄，保证观感一致；
- 截图前把状态栏隐藏（应用本身全屏），避免系统图标干扰；
- 单张图片建议压缩到 200 KB 以内，README 加载更快；
- 如需演示深色主题，可额外增加 `10-dark.png`，并在 README 截图表格中补一行。
